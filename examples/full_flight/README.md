# Эталонный пример полного полёта

Этот каталог содержит полный реалистичный сценарий работы генератора. Набор
хранится в репозитории как общий источник для документации, ручных
экспериментов и интеграционных тестов.

```text
full_flight/
├── input/
│   └── prepared_trajectory.csv  # подготовленная целевая траектория, 45 997 точек
├── reference/
│   ├── expected_gnss.dat        # эталонный GNSS-выход
│   └── expected_imu.dat         # эталонный IMU-выход
└── generate.py                  # потоковый пример генерации
```

Входной файл считывается `DcmTrajectoryReader` чанками через
`pandas float64 → longdouble`, не удерживая траекторию в памяти. Перед
генерацией он выполняет небольшой первый проход только по временным меткам,
чтобы получить глобальный шаг времени. Эталонные файлы используют заголовки и
единицы `DatOutputFormat`. `DcmTrajectoryGenerator` воспроизводит DCM-синтез в
пределах нескольких ULP `float64`.

Короткая потоковая проверка:

```bash
python examples/full_flight/generate.py --points 100
```

Полный прогон:

```bash
python examples/full_flight/generate.py
```

Полный прогон с доказательной проверкой относительно эталона:

```bash
python examples/full_flight/generate.py --check
```

Команда сравнивает все 45 997 строк и завершится ошибкой, если хотя бы одно
число выйдет за пределы четырёх ULP `float64`. В отчёте выводится максимальная
абсолютная ошибка. Это допускает только неизбежное различие последнего разряда
между платформами; конкретное значение зависит от численной среды и обычно
имеет порядок `1e-15`.

Выходные файлы по умолчанию создаются в `examples/full_flight/output/`.
Этот каталог исключён из Git.
